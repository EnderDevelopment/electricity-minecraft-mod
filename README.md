# Electricity! Mod

Electricity! is a Minecraft mod that adds electrical components and systems to the game. It includes placeable wires to connect electronics for power or information sharing, batteries to store power, auto doors for automated access control, computers for advanced functionality, keypads for secure access, switches for manual control, and an ESC (Emergency Stop Circuit) for safety. This mod is designed to enhance the gameplay experience by providing a realistic and immersive electrical system within Minecraft.

## Install

1. Download the latest version of the mod from the [GitHub repository](https://github.com/EnderDevelopment/ElectricityMod).
2. Place the downloaded `.jar` file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure the mod is loaded.

## Use

1. **Place Wires**: Use the wire block to connect electronics for power or information sharing.
2. **Place Batteries**: Use the battery block to store power.
3. **Place Auto Doors**: Use the auto door block for automated access control.
4. **Place Computers**: Use the computer block for advanced functionality.
5. **Place Keypads**: Use the keypad block for secure access.
6. **Place Switches**: Use the switch block for manual control.
7. **Place ESC**: Use the ESC block for safety.
